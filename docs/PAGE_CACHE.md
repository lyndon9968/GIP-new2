# 页面保留与手动刷新

各模块首次打开才加载数据；已访问页面切换离开后隐藏、不销毁，返回不重复查询。
搜索、园区选择、系统设置子页、未完成的弹窗及抄表输入在当前登录会话内保留。
隐藏页面不接收 Escape，弹窗隐藏时释放页面滚动锁。

顶部“刷新”重新读取当前模块／当前设置子页，同时检查当前账号的角色和园区授权。
首次打开、切换园区或抄表月份、保存业务修改后仍读取对应数据。
没有轮询或页面激活时自动重新读取；其他人员的更改需要手动刷新才会显示。

页面缓存只在内存中，不把账单或客户数据写到本地持久存储。
浏览器整页刷新、退出／切换账号、已获知的角色或授权园区变化都会清空缓存。
权限不依靠前端缓存，数据库 RLS 仍按真实登录身份约束每次读写。
已有新增园区草稿机制仍使用 sessionStorage；主动退出登录时清除此草稿。

核心代码：src/lib/PageCache.jsx、src/App.jsx、src/lib/AuthContext.jsx。
Supabase 同账号 SIGNED_IN（可能由焦点恢复触发）和 TOKEN_REFRESHED
仅更新会话，不切换全局 loading；账号变化或 USER_UPDATED 仍处理相应档案。
页面请求使用递增版本号防止较慢的旧园区请求覆盖新园区数据。

本地浏览器模拟接口回归已覆盖：返回零重复查询、手动只刷新当前模块、
设置子页和弹窗保留、抄表草稿、焦点／Token 续期、错误恢复、角色／账号变化、
退出缓存清理及手机刷新按钮。未对线上 Supabase 或 Netlify 执行修改。
这项优化不需要新的 SQL，只需发布前端。
